The datasets analyzed in this study are available in public repositories. The American Community Survey microdata are published by the U.S. Census Bureau, https://www.census.gov/programs-surveys/acs/microdata.html, and were obtained with the Folktables package, https://github.com/socialfoundations/folktables. The gas sensor array drift dataset is available in the UCI Machine Learning Repository, https://doi.org/10.24432/C5RP6W. The CLEAR-10 benchmark is available from its project page, https://clear-benchmark.github.io/. The code that supports the conclusions of this article, with the exact scripts and configurations used for every result, is available as follows. Project name: Data Drift Autopsy. Project home page: https://github.com/NathanC987/data-drift-autopsy. Archived version: https://doi.org/10.5281/zenodo.24470787. Operating system: platform independent. Programming language: Python. Other requirements: Python 3.10 or higher with NumPy, pandas, SciPy and scikit-learn; SHAP, PyTorch, torchvision, OpenCLIP and Streamlit for the explanations, the image models and the dashboard. The results were produced with Python 3.14.8, NumPy 2.4.2, pandas 2.3.3, SciPy 1.17.0, scikit-learn 1.8.0, SHAP 0.50.0, PyTorch 2.11.0, torchvision 0.26.0, OpenCLIP 3.3.0, Matplotlib 3.10.8, Streamlit 1.54.0, CatBoost 1.2.10, cleanlab 2.9.0 and DetectShift 1.0.1.
